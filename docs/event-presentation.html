Deck logic

Слайды должны работать для сцены, а не только для экрана ноутбука

Event-презентация требует другой логики: меньше текста, крупнее акценты, понятная навигация, сильные заголовки и визуалы, которые поддерживают выступающего, а не конкурируют с ним.

Stage slides Speaker deck Social recap Event identity

Сценические материалы должны быть читаемыми, ритмичными и визуально сильными.

Визуальный язык события должен поддерживать масштаб, энергию и запоминаемость.

Communication

Событие продолжается в материалах после финального слайда

После мероприятия важно быстро выпустить recap, цитаты, фото-подборки, итоги, посты и материалы для продаж или PR. Поэтому visual system создаётся заранее, а не после события.
