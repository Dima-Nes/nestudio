# Кейсы работ

Кейс – это подробный рассказ о работе на её странице `nestudio.by/v/<slug>/`. Он идёт сразу под видео.

- Файл кейса: `cases/<slug>.md`. `slug` – тот же, что в `data-slug` карточки в `index.html`.
- Кадры из видео: `media/cases/<slug>/01.webp`, `02.webp` и т. д.
- После правки запустить из корня репозитория `python3 -I tools/build_video_pages.py` и проверить страницу локально.
- Работа без файла кейса остаётся простой страницей с видео.

## Шапка файла

Шапка – между двумя строками `---`, по одному полю на строку: `поле: значение`.

| Поле | Что это | Обязательно |
|---|---|---|
| `title` | заголовок страницы для поисковиков, до 60 знаков | да |
| `description` | описание для поисковиков, до 155 знаков | да |
| `h1` | заголовок на странице | да |
| `lead` | 2–3 предложения под заголовком | да |
| `client` | заказчик | |
| `task` | задача одной фразой | |
| `format` | формат: «вертикальное 9:16, для ТВ и соцсетей» | |
| `duration` | хронометраж `м:сс`, попадает в разметку видео | |
| `services` | что сделали | |
| `tools` | инструменты | |
| `date` | дата публикации кейса `ГГГГ-ММ-ДД` | |
| `cta` | заголовок блока «Нужен похожий ролик?» | |
| `cta_text` | текст этого блока | |

Поля `client`–`tools` выводятся справа в «Паспорте проекта».

## Текст

Абзацы разделяются пустой строкой.

| Как написать | Что получится |
|---|---|
| `## Задача` | раздел (h2) |
| `### Подзаголовок` | подраздел |
| `- пункт` | список |
| `1. шаг` | нумерованные этапы, каждый в своей плашке |
| `> цитата` | цитата: закадровый текст, слова заказчика |
| `**важное**` | жирный |
| `[текст](https://…)` | ссылка |
| `![Подпись к кадру](01.webp "0:12")` | кадр с подписью. Время необязательно; если оно есть, клик по кадру запускает видео с этого момента, а в разметке появляется «ключевой момент» для Google |
| 2–3 строки кадров подряд, без пустой строки | галерея |

Раздел `## Частые вопросы` особый: каждый `### Вопрос?` с абзацем ответа под ним превращается в раскрывающийся вопрос и разметку FAQPage.

## Кадры

- Брать резкие, яркие кадры, без переходов и полупрозрачного текста.
- Формат WebP, длинная сторона 1280 px:
  `ffmpeg -ss 12.5 -i video.mp4 -frames:v 1 -vf "scale='if(gt(iw,ih),min(1280,iw),-2)':'if(gt(iw,ih),-2,min(1280,ih))'" -c:v libwebp -quality 80 01.webp`
- Подпись – одно короткое предложение о том, что в кадре. Можно с естественной поисковой фразой, без перечня ключевых слов.

## Правила текста

- Только факты из проекта. Не выдумывать результаты и цифры.
- Не публиковать цены и сроки работы (ни в паспорте, ни в тексте, ни в FAQ), внутренние заметки и переписку.
- Частные заказы (поздравления, свадьбы, семейные видео) – без имён героев: «частный заказ», «именинница», «невеста».
- Цитаты заказчиков – только из благодарственных писем и переписки, где заказчик сам дал оценку; должность и компания, без телефона.
- Только короткое тире «–». Длинное «—» запрещено.
