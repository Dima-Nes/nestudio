# Чат на сайте nestudio.by → Telegram

Окно чата на сайте (круглая кнопка внизу справа → «Чат на сайте») отправляет сообщение этому маленькому серверу на Cloudflare.
Он пересылает его в Telegram через бота. Ответ «Ответить» на это сообщение в Telegram возвращается посетителю в окно чата.
Пока сервер не подключён, чат копирует текст и открывает наш Telegram @nestudiopro – сообщения не теряются.

Бесплатно: тариф Workers Free (100 000 запросов в день) и KV Free.

## Быстрое подключение (рекомендуется, ~5 минут)

1. В Telegram у @BotFather: `/newbot`, имя «nestudio · сайт», ник например `nestudio_site_bot`. Скопируйте токен.
2. В терминале из папки сайта:
   ```bash
   bash tools/chat-worker/setup.sh
   ```
   Скрипт попросит войти в Cloudflare (в браузере), вставить токен (он не отображается и хранится только в Cloudflare)
   и написать боту `/start`. Остальное – хранилище, сервер, связь с ботом и включение чата на сайте – он сделает сам.
3. Выложите сайт (`git push`).

## Подключение вручную (если скрипт не подошёл)

1. **Бот.** В Telegram откройте @BotFather → `/newbot` → имя, например «nestudio · сайт», ник, например `nestudio_site_bot`.
   BotFather пришлёт токен. Токен – как пароль: никому не пересылайте, в том числе в чат с ИИ.
2. **Куда приходят сообщения.** В личку (напишите своему боту `/start`) или в группу «Заявки с сайта» (создайте группу, добавьте бота).
3. **Сервер.** На компьютере с Node.js, в этой папке:
   ```bash
   npx wrangler login
   npx wrangler kv namespace create CHAT
   ```
   Вход – аккаунтом Cloudflare, где домен nestudio.by. Полученный `id` впишите в `wrangler.toml` вместо `PUT_KV_ID_HERE`.
   ```bash
   npx wrangler secret put BOT_TOKEN
   npx wrangler secret put WEBHOOK_SECRET
   npx wrangler deploy
   ```
   На первый вопрос вставьте токен бота, на второй – любую длинную строку (запомните её для шага 4).
   После `deploy` будет адрес вида `https://nestudio-chat.<имя>.workers.dev`.
4. **Связать бота с сервером.** Откройте в браузере (подставьте свои значения):
   `https://api.telegram.org/bot<ТОКЕН>/setWebhook?url=https://nestudio-chat.<имя>.workers.dev/tg&secret_token=<WEBHOOK_SECRET>`
5. **Номер чата.** Напишите боту `/start` (в группе – `/id`). Бот ответит `Chat id: …`. Выполните `npx wrangler secret put CHAT_ID` и вставьте это число.
6. **Включить на сайте.** В `index.html` в строке `<section class="chat" id="chat" … data-endpoint="">` впишите адрес сервера из шага 3,
   запустите `python3 -I tools/build_video_pages.py` и выложите (`git push`). Адрес не секретный – его можно просто сообщить тому, кто выкладывает сайт.

## Как отвечать
Сообщение в Telegram выглядит так: «Сообщение с сайта nestudio.by, имя, связь, страница, текст». Нажмите на него «Ответить» и напишите ответ –
посетитель увидит его в окне чата на сайте (если окно закрыто – при следующем открытии, история хранится 30 дней).
Можно и сразу позвонить или написать по контакту, который он оставил.

## Защита
- Принимает сообщения только с nestudio.by и nestudio.site.
- Не больше 8 сообщений за 10 минут с одного адреса, скрытое поле от ботов.
- Ответы из Telegram принимаются только из чата CHAT_ID и только с секретным заголовком вебхука.
